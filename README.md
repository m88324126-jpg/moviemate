# moviemate
MovieMate — это сайт для любителей кино, где смотреть фильмы и сериалы становится игрой. Тут можно проходить квесты по неделям, зарабатывать бейджи и награды, открывать новые подборки и категории контента. Интерфейс простой и аккуратный — без лишних кнопок, чтобы легко ориентироваться и не отвлекаться от главного.
